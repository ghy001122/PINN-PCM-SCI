## 4. 必须正面处理的归因边界和反证

1. **全网格与抽样覆盖。** E在使用的训练时刻约束全部3200个电学单元；F虽然计算全网格面算子，却仅惩罚每时刻128个采样单元。当前结果比较完整训练方法，包含硬/软约束与训练覆盖差异。是否只需将软电学残差改为全网格均值即可追平，是最直接的替代解释之一。
2. **初值、参数与目标映射。** E初始V来自电学解，F来自原V头；可训练参数、V观测梯度和优化路径不同。相同父态T/phase与相同更新上限不能排除这些差别。请判断哪些需要额外反事实，哪些只需限定主张；避免穷举所有组合。
3. **相态与完整事件未全面改善。** E第一周期recall=0.882492，低于0.9；第二周期timing=0.00752857，大于0.005。F_raw/F_bal第二周期timing分别0.00252857/0.00489091，比E更好，但各自第一周期仍有失败项。全部strict为false。主图与完整事件表均保留这些取舍。
4. **剩余PDE必要性仍UNKNOWN。** E与F都训练热/phase残差，E优于F不能替代E对D_E的独立比较。D_E表现仍很强。请判断论文怎样保住真实PINN核心作用，同时诚实处理尚无独立热/phase残差收益，而非要求每个辅助组件都制造一个阳性。
5. **解释性恒等式不是经验创新。** 同一正电导、锚定图和固定σ/驱动下，P(v)−P(v†)=(v−v†)^T A(v−v†)≥0。保存曲线符合该总耗散下降关系，但它不保证参考误差、局部q或原热轨迹更准。电流平衡、功率一致性与解方程存在依赖，不能包装成多个独立成功证据。
6. **外推与来源。** 当前只有一个继承父态和已反复查看的nominal；两种F不是独立初始化。没有新观测规则、完整新案例、formal OOD、材料标定、实验或加速证明。隐式微分、solver-in-the-loop、Adam/L-BFGS及一次标量校准都有先例；论文中的原始来源用于透明归因，不应分别包装成原创。
