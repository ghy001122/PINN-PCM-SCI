# 使用运行前登记和有序 KC 裁决

每个正式运行在启动前登记方法、案例、种子、预算和停止合同，checkpoint 只由独立物理审计集上的原始方程、初边值、界面、电路与守恒指标选择；只有方法外部的执行损坏可保留原记录后按原配置精确重放，算法 NaN、方法性 OOM、不收敛、预声明目标事件缺失或时钟可容许性失败均保守计作方法失败，禁止换种子、延长预算或按案例救援。正式论文采用单一有序逻辑合取链：KC 在结构主端点上胜过匹配 raw-time，并同时胜过一般单调和动力学错位时钟，随后通过原物理非劣门并在独立器件端点上胜过同一 raw-time；只有全部通过形成 `KC_GO` 和限定工作域内的动力学特异数值方法主张，强方法族基线完整报告但不支持 SOTA 主张，正式配置、失败台账、物理合同、环境与分析产物随投稿归档。
