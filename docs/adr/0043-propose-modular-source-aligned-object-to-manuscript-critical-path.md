# 0043：提出模块化来源对齐对象到论文初稿的最短关键路径

- `status`: `PROPOSED`
- `proposed_at`: `2026-08-26`
- `decision_scope`: `PLAN_DRAFT_ONLY_NO_RESEARCH_EXECUTION`
- `supersedes_for_planning`: `COMPLETED_PACKAGE_A_TERMINAL_PLAN_ONLY`
- `preserves`: `ADR_0042_AND_ALL_BOUNDED_NEGATIVE_EVIDENCE`
- `claim_status`: `BOUNDED_SOURCE_PORTFOLIO_NO_GO_NO_METHOD_EVIDENCE`

## 背景

授权包 A 已以 `PORTFOLIO_NO_GO_PACKAGE_A_FROZEN_3_FAMILIES_11_CARRIERS` 收口：三个候选都在求解前因单一来源链合同不完整而失败，没有对象锁定，所有 oracle、strong-raw、CTH、formal 与方法主张均为 `NOT_REACHED`。该结论证明当前单链筛选合同在冻结组合内没有得到对象，但不证明透明 clean-room 派生对象、CTH 或 PINN 不可行。

用户提供的外部对抗审查建议把下一路线改为“主锚点来源 + 兼容模块来源 + 有限分支”的模块化 source-aligned clean-room 合同。项目实时证据支持修订来源量词，但不支持降低二维物理、绝对协议、来源响应、事件、收敛、strong-raw、控制、公平或 formal 门。

## 拟议决定

1. 以 [PLAN-MSA-01](../plans/NEXT_ACTIONS.md)作为唯一 live PLAN 草案。它只替换已完成的 Package A terminal plan，不撤销 ADR 0042 或任何历史 No-Go。
2. 候选对象必须有一个主锚点来源，自包含器件身份、二维拓扑、PDE/interface、IC/BC、绝对协议/history、端口和空间响应锚点及许可。
3. 每个 bundle 最多两个兼容模块来源，只能补同材料条件下的 transport 参数、热物性或主锚点已明确采用的本构子合同；不得补主锚点缺失的几何、必要 BC/interface、绝对时间、协议顺序、响应锚点或新机制。
4. 对象优先零分支，最多一个二值非拓扑 `UNKNOWN_BRANCHABLE` 轴。第二个不确定轴或任何 `UNKNOWN_FATAL` 直接拒绝候选；所有允许分支必须通过后续全部门，禁止事后删枝。
5. 对象仍按方法盲规则选择。CTH 只保留在 conditional parking lot；只有独立 oracle、两周期事件、strong-raw competence、transport-side 有限预算表示瓶颈、非神经一侧相关性与 novelty veto 全部通过后才可准入。
6. development 必须先比较 strong raw、SA/direct residual-Jacobian、smooth6 与 CTH；正向路线幸存后补 wider raw、extra-work raw、smooth-absolute、wrong-knot、independent-per-view 与 IND bundle 控制。formal 只保留 CTH、strong raw 和最强非 CTH challenger 三臂。
7. 论文 skeleton 可在另批本地写作包后与研究并行；只有 sealed formal PASS 后才能称 `EVIDENCE_COMPLETE_POSITIVE_CTH_MANUSCRIPT_DRAFT`。
8. 本 ADR 保持 `PROPOSED`。用户批准计划内容不等于授权执行；新的来源审查必须显式批准 `MSA-A`，后续 CPU、GPU、formal、写作和 Git/外部发布逐包独立。

## 被拒绝的替代方案

1. **继续寻找一条自包含全部参数和资产的单一来源链。** 已在多轮筛选中成为主要耗时与早停来源，且不是 clean-room derived/synthetic 对象的必要条件。
2. **直接构造任意 synthetic benchmark。** 缺少主锚点的协议、响应和器件身份会让论文故事退化为人为制造的 CTH 友好任务。
3. **把旧 HFO、TaOₓ 或其他失败候选改名重开。** 会抹去已冻结来源矛盾并制造结果导向对象选择。
4. **允许模块来源补几何、BC、协议或响应锚点。** 会形成不可审计的 Frankenstein 对象，无法支撑 source-aligned 表述。
5. **为保证论文阳性自动切换对象或方法。** 会把科学接受标准变成论文产出标准，产生研究者自由度和选择偏差。

## 后果

- 下一次可申请的唯一科研包是 `MSA-A_CONTRACT_AND_METHOD_BLIND_SOURCE_SCREEN`；当前仍为 `NEXT_RESEARCH_EXECUTION_AUTHORIZED=false`。
- 模块化合同提高了对象可重建概率，但主锚点门更清楚；若两个 bundle 或预算耗尽仍无对象，记 `MODULAR_SOURCE_SCREEN_NO_GO` 并关闭当前 CTH 缺陷输运论文方向。
- 正向初稿只能是条件结果，不能承诺。首个硬门失败时保留可复核负证据，但不把负 dossier 冒充二区正向论文。
- domain-modeling 的术语边界将同步到 `CONTEXT.md`，确保主锚点、模块来源、fatal/branchable unknown 和证据闭合稿件在状态文件、计划与论文口径中含义一致。
