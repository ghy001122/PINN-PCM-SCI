# 0041：采用“一对象—一瓶颈—一论文”目标并授权方法盲筛选包 A

- `status`: `ACCEPTED`
- `accepted_at`: `2026-08-26`
- `decision_scope`: `ONE_OBJECT_ONE_BOTTLENECK_ONE_PAPER_PACKAGE_A`
- `authorization`: `SCREEN_AND_GOVERNANCE_ONLY`
- `claim_status`: `NO_OBJECT_NO_METHOD_CLAIMS`

## 背景

HFO-NP-v1、Ta₂O₅/TaOₓ C1 及更早对象均已在各自来源、事件或实现合同内有界终止；当前没有对象、oracle、strong raw 或方法证据。上一轮 TaOₓ 审查正确识别了 paper–model `a=0.32/0.16 nm` 冲突，但把单一家族失败同时用作候选组合终止，不能服务于用户随后接受的“方法盲、首个通过即锁定”的新目标。

用户已接受两轮对抗审查的全部推荐，并明确批准授权包 A。目标是以最短可证伪路径形成一个 source-aligned clean-room `derived/synthetic` 二维氧化物电—热—内部态对象；只有独立 oracle hinge relevance 与 strong-raw 局部瓶颈同时成立时，CTH 才可能进入后续另行授权的 development。

## 决定

1. 当前路线采用 `ONE OBJECT → ONE BOTTLENECK → ONE PAPER`。对象按来源、二维闭环、事件/oracle 可资格化概率和数值成本方法盲排序；选择前不得使用 CTH、wrong-knot 或方法表现。
2. `CANDIDATE_NO_GO` 只关闭该候选；只有冻结候选组合全部失败或包 A 的时间/来源预算耗尽，才记 `PORTFOLIO_NO_GO`。首个通过对象立即锁定；锁定后任何 object/oracle/hinge/raw/method/formal 硬失败都关闭当前论文路线，不返回候选池救援方法。
3. clean-room 来源硬门要求方程、本构、参数层级、单位、二维几何、IC/BC/界面、绝对协议/history、来源响应锚点、版本/许可及 `A/A′/ENGINEERING` 透明闭合。作者内嵌 raw 全场解与作者预封 qualification/development/formal 角色不是其本身的来源硬门；它们由后续独立 oracle 和冻结 case generator 建立。
4. 未解释的 paper–code 因果参数冲突仍不得猜测修补。只有在冲突被预先定义为透明有限分支、且所有可容许分支以后均能通过来源响应、事件和不确定性门时才可保留；否则拒绝候选。TaOₓ C1 的既有 No-Go 不被重开。
5. HFO、TaOₓ C1、VO₂/related-oxide、Q-POP、R1、R2/FerroX 及其他历史 No-Go 均保持原证据边界。新筛选不得通过改名或复用旧输入重启它们。
6. future CTH identity 的 blind off-grid 点必须与 smooth6 构造节点及 smooth-absolute 选择点不相交；若历史 HFO ADR 0039 的 `δ=±1/4` 同时承担插值与 blind 角色，则本决定对未来路线覆盖该双重用途。
7. 本次只授权包 A：有界一手来源/prior-art 只读审查、必要的本地治理同步和来源报告。`0 object build / 0 solve / 0 training / 0 PINN / 0 GPU / 0 formal / 0 paid compute / 0 Git publication` 保持不变。

## 后果

包 A 将在最多 48 小时、最多 12 项新增一手载体、最多 3 个新对象家族内停止于首个 PASS 或组合耗尽。若对象通过，只能形成对象锁定和第一轮 novelty 门的输入；任何 object/oracle 实现仍需授权包 B。CTH、strong raw、development、formal、GPU、本地论文成稿和 Git/外部发布分别需要后续明确授权，不能从本 ADR 或阶段门通过推断。
