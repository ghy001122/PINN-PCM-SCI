# 0026：允许透明派生对象与有界方法重组继续新 idea 筛选

用户明确纠正：两次来源闭合扫描的零候选结果不得解释为禁止后续换材料、改物理闭合、调网络、改损失/训练控制流、捆绑模块或迁移论文 idea。项目继续采用“来源模块 A → 透明适配 A′ → 有界排列组合 → 最小判别证据 → 论文故事路由”的研究方法。

来源扫描的历史事实不变。`BOUNDED_ZERO_CANDIDATE` 与 `EXPANDED_OXIDE_ZERO_CANDIDATE` 只关闭其冻结的“同一来源链直接提供完整二维对象”合同，不否定把多个有来源模块组成新的派生物理对象。跨来源组合必须逐项记录原始用途、方程/接口、参数层级、许可和改动；新系统一律标为 `derived/synthetic`，不得冒充作者实现、同源 source-complete oracle、实验真值或材料本征事实。缺失量可以作为有物理理由的工程选择进入新合同，但不得伪造来源。

材料、几何、边界、网络输入输出、表示、残差、采样、优化、协议、solver coupling、不确定性、评价与证据合同都可成为适配层。直接迁移模块不必为制造新颖性而强行修改；贡献可位于适配、接口、工作流、功能组合、验证或可组合性。组件是否已有先例、组件在旧合同中是否失败、以及新组合的 claim status 必须分别记录。旧 No-Go 继续绑定旧对象、接口、case、预算和指标；只有前提、接口、任务或主张实质改变时才可在新组合中重新评价。

组合可以从 idea 阶段联合设计，不再把“KC 必须先独立通过、第二模块才能参与组合设计”解释为候选生成禁令。若某模块被列为论文正向贡献，仍须由强基线、关键消融和完整组合证明其预声明增量；没有独立增量的模块可以作为透明 supporting module，但不得被包装成独立创新。若只有组合交互成立，可主张功能组合、接口协同或 composability，不得倒推两个模块各自优越。完整组合若没有性能、功能、接口、守恒、稳健性、泛化、验证或可组合性中的预声明增量，则必须记录证据不足。

论文故事允许并要求主动构造，但故事必须在证据前明确“问题—瓶颈—来源—适配—能力—基线/消融—claim”。禁止隐藏来源、抹去负结果、事后移动阈值或 OOD、把工程选择写成实验事实、把复制模块冒充原创、虚报优先权或编造数据。学术叙事可以改变研究任务和 claim，但不能改变已经发生的证据。

该决定在下一 idea 筛选范围内细化并部分覆盖 ADR 0019/0022 对“自由 A′/跨来源对象”的全局禁止解释，以及 ADR 0021/0025 对组合候选必须串行生成的解释；它不改写这些 ADR 所绑定的历史 KC 合同、来源扫描和负面证据。每个被选中的新组合仍须通过 PLAN → 用户批准 → EXECUTE，并在 FULL_DESIGN 中冻结物理对象、强基线、关键消融、完整 case/OOD、预算和停止条件。本 ADR 只授权只读 FAST_SCAN、必要的定向 source card 和计划设计，不授权 solver、代码实现、训练、formal 或 GPU。
