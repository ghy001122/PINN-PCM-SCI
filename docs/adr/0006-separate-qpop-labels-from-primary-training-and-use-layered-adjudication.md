# 隔离 Q-POP 内部场标签并采用分层正向裁决

主训练不使用 Q-POP 瞬态内部场标签；合格 Q-POP oracle 仅用于物理合同、案例设计、有限开发选择和独立评价，稀疏场锚点只作为单列 solver-assisted 消融。动力学特异性的最低比较包括标准及活动容量匹配的 raw-time PINN、作为实现链路检查的 identity clock、消除原点与尺度或跨度退化但不与 \(K_\eta\) 局部对齐的一般单调时钟、相对于实际采样测度保持边际分布且保持可比光滑度的动力学错位时钟，以及代表性开发案例上的 eta-only 与 all-field clock；具体 gauge 与错位映射在 PhysicalContract 和开发探针后预声明冻结，不能按正式结果选择。主公平轴是相同的实际计算预算与开发调参预算，固定点数和更新数仅作辅助视图，Fourier、因果训练和自适应采样属于保留原生机制的方法族基线而不是机制负控；正面结论仍须同时闭合结构主效应、动力学特异性、原始物理与守恒非劣、完整案例和种子稳健性及预声明独立器件后果，算法自身发散计入有效方法的失败率，具体指标、聚合、缺失事件规则、阈值和非劣界在有界 pilot 后、正式投票运行前冻结。
