# 用显式处置状态和双侧证据门控制 KC 到 PHA 的转换

路线使用互斥处置：合同或外部依赖缺失为 `BLOCKED`，外生执行、方程、pullback、事件、公平性或防泄漏验证违规为 `INVALID`，有效基线已达数值或实用误差地板为 `NO_BOTTLENECK`，有效但冻结预算内证据不足为 `INCONCLUSIVE_BUDGET_EXHAUSTED`，有效且有辨别力的实验未通过预声明机制、物理或器件门为 `KC_SCIENTIFIC_NO_GO`，通过全部分层正向门为 `KC_GO`；算法在正确合同下的发散属于方法表现，不得作为 `INVALID` 剔除。只有 `KC_SCIENTIFIC_NO_GO` 可以启动新的 PHA 诊断，但不得以 KC–Fourier、KC–sampling 或 KC–PHA 叠加救援原 KC 主张；表示欠分辨和采样稀缺必须分别获得独立诊断支持，单侧信号转向更简单的单侧路线。PHA-MF 还须经新预注册与新颖性刷新，使用未参与 KC 路线选择的新留出案例，并以同一标量门同时控制表示和采样、相对 separate-gates 显示预声明独立增量后，方可重新审批为正面路线。
