# 0022：采用来源闭合一票否决的 VO₂ 优先候选组合

- `status`: `ACCEPTED`

- `decision_scope`: `FUTURE_SOURCE_OBJECT_ADMISSION_AND_PORTFOLIO`

未来候选对象的来源闭合是不可由事件漂亮、复现便宜或潜在论文价值补偿的一票否决：必须同时具有可引用的原始论文、固定版本且许可明确的公开实现、闭合几何/接触/边界/驱动/方程/参数/状态语义的资料，以及可复现或重新生成的参考输出。来源对象可以是纯数值模型，但只能产生合成数值 oracle，并须另行通过复现、离散收敛、守恒与数量级检查；实验资料只作外部一致性支持。允许的本地改动只限环境迁移、格式适配、无量纲化和经等价性核验的离散修改，改变几何、接触、驱动、动力学或本构会形成必须单独准入的派生物理对象。

候选组合采用 VO₂ 优先的 `1 active + 最多 2 fallbacks`，禁止三条路线并行执行；按来源闭合、目标事件适配、二维多物理完整性、复现负担、raw headroom 和论文价值依次裁决，历史无事件、整域同步翻转、空间不收敛和结果导向 `A_PRIME` 失败类型用于前置排除。若一次有界 VO₂ 来源扫描没有得到合格活动对象，才可另行请求用户批准，将后备范围扩到机理相近的氧化物相变/忆阻体系并同步改写论文物理主张。本 ADR 不授权来源检索、材料扩张、实现或运行。
