连续 sharp moving front 不再是下一路线的唯一准入对象；目标改为二维电—热—结构模型中空间异步、局部、部分覆盖且可恢复的结构相事件，移动前沿只保留为关键诊断。未来数值对象必须由公开论文、作者代码或公开数据闭合决定事件拓扑的几何、接触、边界、驱动和状态语义，不再构造来源不完整的自由 `A_PRIME` substrate。

该决定覆盖 Q1 中“移动前沿是硬准入条件”的未来解释，并取代 ADR 0018 的 EAF `A_PRIME` 路径作为后续对象选择方式；Q2–Q23 的材料工作域、PINN 身份、强基线、case 隔离、checkpoint、评价和 claim gates 保持不变，历史 EAF 事实不改写。本 ADR 不选择具体公开对象、不冻结数值阈值，也不授权检索、实现或实验。
