用户接受 grill-with-docs Q44–Q48 的推荐答案。若对象、事件、raw competence 与瓶颈前门未来全部通过，首篇论文只允许一个由证据选出的、真正承担增量因果链的 PINN 算法或网络机制进入 headline。HFO-NP-v1 派生对象、证据路由、完整案例隔离、训练公平与失败治理均为必要支撑，但不与该方法机制并列为第二个主要创新。当前不得提前把 SRF、cKC-NP、二者交互或任何其他模块写成已选主方法。

formal generalization 只允许落在 G0 来源合同最终认可的 HFO-NP-v1 有效域内，以完整几何、接触/热边界、协议和初态家族为拆分单位，并保持逐案例独立训练。首篇论文不作跨材料、跨器件的冻结 operator 或全局 surrogate 主张；哪些家族成为主 OOD 轴须等来源合同和事件资格完成后另行冻结。

方法效用采用双层表述：在实际计算匹配下，完整局部事件保真度和全部物理守卫是主要裁决；达到预冻结事件保真度所需的计算、墙钟、内存或自动微分代价是次要 Pareto 证据。成本优势不能挽救 raw 不胜任、主端点失败或任一硬物理守卫失败，也不能通过事后加权综合分数替代主要裁决。

首篇论文范围保持 forward PINN 求解。逆问题、参数识别、不确定性量化和跨对象代理只能列为未来工作或单独路线，不得在首篇论文中成为共同主要任务，也不得用它们弥补 forward 方法证据不足。

新颖性必须进行两次有界刷新：第一次在 load-bearing primitive 已冻结、任何方法 pilot intent 生成前；第二次在 formal OOD 合同或论文主张冻结前。若届时的一手工作覆盖该 primitive、同一因果主张与可比的完整事件证据，须在执行前停止、降格或收缩主张。组件级碰撞的具体裁决仍待后续问题冻结；任何一次“未发现 exact bundle”都不构成世界首创、FTO 意见或 novelty clearance。

本 ADR 只冻结论文身份、外推边界、效用层级和新颖性刷新时点。它不选择方法 primitive，不冻结具体 OOD 轴、案例数、seed、预算、阈值或统计规则，也不授权来源检索、solver、PINN、training、formal、GPU、付费计算或 Git 发布。G0–G1 来源与事件前门、当前 blocker 和 `NO_SCIENTIFIC_METHOD_CLAIMS` 保持不变。
