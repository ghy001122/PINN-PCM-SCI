# 0021：第二正向模块必须同时通过独立门与组合增量门

- `status`: `ACCEPTED`
- `accepted_at`: `2026-08-21`
- `decision_scope`: `FUTURE_KC_METHOD_MODULE_ADMISSION`
- `claim_status`: `PROPOSED_METHOD_NO_NUMERICAL_EVIDENCE`

KC 仍是首篇正向方法论文的必选核心，首篇最多包含两个正向模块。第二模块只有在合格 oracle、胜任的强 raw 与互斥开发案例上，超过匹配基线和关键消融、同时通过原物理非劣，并针对已验证且与 KC 不同的剩余瓶颈时，才算“模块独立通过”并获准进入组合开发；实现存在、单一指标改善或未通过模块均没有捆绑资格。

组合开发至少比较 raw、KC、第二模块和 KC+第二模块，并按实际计算量匹配预算。组合必须超过最佳单模块，或实现预声明且可独立裁决的不同功能增量；若只与最佳单模块持平，则保留更简单的单模块。首篇只允许一个活动组合、最多两个后备组合；KC 或任一模块失败后均不得用组合救援。该决定仅在上述双门通过时条件式覆盖 ADR 0005 的“唯一正向模块”限制，不改变 Q13/ADR 0008 的禁止组合救援，也不授权任何模块实现或实验。
