# 用有界 pilot 冻结时钟优化与可容许性

开发池只比较预注册的 `full-gradient/clock-loss stop-gradient` 与 `joint/identity-warm-up` 二乘二协议，保持前向残差、配对种子和实际计算预算一致，并按数值有效性、原始物理非劣、无动力学塌缩或时钟失控、开发结构端点及失败率一次选择；并列时采用 `stop-gradient + joint`，正式池前全局锁定，四种协议均不合格时停止而不增加救援路线。除构造性单调外，开发阶段还须冻结结构时钟的空间导数、坐标条件数和回拉放大守卫；至多比较一个尺度化正则方案，若采用则所有 learned-clock 机制臂共同使用，正式结果后不得裁剪、平滑或调强，正确实现下越界计作方法失败。
