## 决定性结论

**VERIFIED：六个完整耦合 PINN 终点、两条细化参考和一次干净归档重评分均已完成。当前 GPU 实例已回收关机。** 新网络并未在旧参考上建立预声明的匹配增量，但参考补证和对照确实补强、限定了论文主张。

1. **VERIFIED：原有主要方法结论经此次时间扰动保留。** 四个历史 E/F 配对的器件层 B 均保持通过；历史 E/F、E/B_E 的全部 A/B 裁决不变。原协议 seed43 对 B_E 的不足也保留。这是同一空间网格、两份时间参考之间的结果，不是空间收敛或连续体认证。
2. **VERIFIED：继续优化解释了主要新增相态改善。** E_C 相对原 E 的 raw phase RMS 在 seed29/43 分别下降约 7.65%/8.89%。E_R、E_I 对 E_C 在两个参考下均未通过原相态层 A 或器件层 B；旧参考下也没有严格能力增量。
3. **VERIFIED：门控产生了可测量的器件变化与相态取舍。** 旧参考下，E_I 对 E_C 的电流误差下降 6.72%/6.58%，功率下降 7.54%/7.24%，没有达到 10% 效应门。相态误差在 seed29 改善 1.58%，在 seed43 恶化 2.04%。E_I 对等参数量 E_R 也没有原 A/B 增量，不能把门控写成已确认的独立创新；未过门不等于统计零效应或等效。
4. **VERIFIED：严格门发生一个参考敏感的跨越。** 仅 E_I/seed43 在细化参考下通过全部原严格双周期要求及相应非劣条件；旧参考下不通过。这个参考特定的严格增量必须保留，但不能称两参考、两父态均确认的能力提升。
5. **VERIFIED：数组复现闭环成立。** 干净目录、隔离 Python、仅 NumPy 的一次复算重现了旧主表、事件、A/B及全部 16 个对象的旧/新参考结果。没有加载模型或求解 PDE，不冒充从头训练复现。

**SUPPORTED_INTERPRETATION：**当前证据支持保留原电学消元方法主线，将普通增容和冻结界面门作为有边界的表示反事实。它限制了“只需增加该相态表示能力即可解决当前缺口”的解释，没有证明网络容量普遍无关，也没有隔离一个唯一训练失败根因。
