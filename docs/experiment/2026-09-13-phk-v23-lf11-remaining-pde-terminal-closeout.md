1. **强基线收益保住了。** P1/P_kappa 对同电学层 B_E 均通过原 A/B，raw Ephi 低39.99%/40.03%、功率误差低58.71%/56.69%。P1 同时保留对原 D_E 的对应层非劣；P_kappa 对原 D_E 的电流误差高5.21%，不能宣称全面优于原强端点。
2. **大部分新增相态拟合改善来自共同继续优化。** D_C 的 raw Ephi 相对原 D_E 已低7.85%；P1/P_kappa 对 D_C 的额外下降仅0.65%/0.73%，S 下降1.21%/1.35%，均未到10%门。不能把从旧父态到新 PINN 的全部下降归因于新增 PDE。
3. **从“小 loss”推进到完整梯度和实际反事实。** D_E 的加权剩余 PDE 梯度仅为规定尺度 G 的0.1077%，参考盲规则冻结 kappa=92.8404908293；phase 方程对 T（含适配器）的参数梯度范数是对 phase 头的9.16倍。后者是固定参数化下的局部事实，不是全程因果或普适敏感度。原 P_E 在训练池和旧审计池的共同 C+F/J 都较差，不能仅归因于审计泛化。
4. **全局增权改变了残差，但主要作用于热项。** P_kappa 相对 D_C 的 J 在训练/审计池下降6.59%/2.35%；热项下降6.75%/2.39%，phase 审计几乎不变（+0.124%）。P_kappa 相对 P1 的 J 下降5.99%/2.19%。同时，P1 在两池取得更低共同 C+F。它们是不同目标的真实取舍。
5. **部分事件进展与器件代价并存。** P1/P_kappa 的第一周期 recall 均越过原0.9门；两周期 precision、mass、recovery 及内在事件条件满足，recovery 均为1。剩余严格条件是周期2 timing 分别0.008633/0.007637>0.005，故 strict 均为 false。P_kappa 的周期2 timing 比 D_C 好14.73%、比 P1 好11.53%，但周期1 timing 比 P1 差19.70%，仍在0.005内。
6. **物理残差降低没有转成联合器件收益。** P_kappa 相对 D_C 的电流/功率误差增加5.03%/5.71%，相对 P1 增加4.42%/4.90%；局部 q NRMSE 相对 D_C 增加1.26%。这不是仅仅擦过5%非劣门：两项功能主指标均未向10%改善方向发展。采样时间/FV 热平衡代理下降约2.37%，仍不能替代实际 AD 训练残差、器件评分或连续体真值。

**SUPPORTED_INTERPRETATION：** 本轮把“剩余 PDE 作用可能太弱”细化为：父态原始一阶范数确实小，一个预声明强度修正能降低两池热主导残差、改善部分事件，却未提供所需的独立预测增量。小范数不是 L-BFGS 更新份额；此次目标也没有穷尽其他强度或所有 PINN。结束这个配方，不再以继续增权、旧 hard lift、旧电学归一化或 latent/expert 队列救援。

**当前可入稿的主线：** 固定导电率的电学接口修复 → 超过同层强插值的神经重建 → 完整方程块/参数头诊断 → 同父强度反事实下的残差—事件—器件取舍。隐式电学层、半电阻焦耳沉积与热单元残差是可复用方法接口；其必要性、剩余 PDE 正面优势及独立案例确认尚未闭合。通用求解、隐式微分、L-BFGS、kappa 和条件误差界不分别包装成创新。

**HYPOTHESIS / UNKNOWN：** 原始固定热目标与细网格器件读出的数值适配、PDE 相对已见观测的独立信息，以及单一初始化以外的稳健性仍待区分。新增的是这一明确取舍的有界证据，并非整个 PINN 类别失败或实验氧化物器件验证。
