# PINN-PCM-SCI

面向“物理信息神经网络 × 氧化物相变材料/器件/忆阻器/神经形态计算”的纯软件研究项目。目标是以可复现、证据闭合的方式，从 idea 筛选逐步推进到中科院二区 SCI 定位的论文初稿。

## 当前状态

项目已完成 Codex 文档骨架初始化，但**尚未开始正式学术研究**。目前没有已选定的研究 idea、物理模型、数据集、PINN 架构、数值实验或科学结论。详见 [active_phase.md](active_phase.md) 与 [PROJECT_STATE.md](PROJECT_STATE.md)。

## 项目边界

- 主题：PINN 与氧化物相变材料、相变器件、忆阻器或神经形态计算的交叉。
- 研究形式：纯软件闭环；传统求解器产生的数据只能称为合成数值数据，不能冒充实验验证。
- 方法要求：正面方法论文中 PINN 必须承担核心功能，且算法或网络创新必须有相对强基线的可测增量。
- 物理要求：论文主体采用二维及以上真实器件结构，并至少闭合电—热—相态因果链。
- 交付目标：完整论文初稿、可复现代码/配置/数据/图表及证据映射；目标定位不是接收承诺。

## 工作方式

1. 每次任务先读取 `AGENTS.md` 中列出的权威链。
2. 先核对当前阶段是否授权该任务。
3. 学术工作围绕论文主张、证据产物和停止条件推进。
4. 本地研究产物形成后，再将重要过程或阶段成果作为独立工程操作提交到云端。
5. 实现完成、运行完成、数值有效和科学主张成立分别判定，不相互替代。
