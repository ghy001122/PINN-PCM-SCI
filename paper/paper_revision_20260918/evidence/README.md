These are the two clean D_E ablations, not new independent protocols. Readout/reference identity remains explicit in every score.

Git alone therefore does not yet provide complete array rescoring or an independently repeated training experiment.

Content and visual acceptance records describe the completed internal AI-assisted review, not independent peer review. Compute closure is a sanitized summary.
