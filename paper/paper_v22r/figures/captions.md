# Main-figure captions

## Figure 1 — Frozen route and terminal outcome

The v1.1 alignment gate and four-arm V100 nominal run completed, but all four
local nominal evaluations failed event competence. The immutable No-Go prevented
confirmation training, candidate freeze, and stress-reference access. The two
stress references remain sealed and unread.

## Figure 2 — Training and compute

Logged PDE loss, measured seconds per update, and peak allocated GPU memory for
the four frozen arms. All arms reduced PDE loss and completed without nonfinite
failure. Physics-loss convergence did not imply reproduction of the localized
phase events. Sampler arms used more peak memory because candidate scoring was
active.

## Figure 3 — Phase-event collapse

Reference phase fields and four final-checkpoint predictions at the reference
peak of each cycle. The reference shows two localized lobes near the lower
heaters. Every PINN prediction remains near zero at both peak times and never
crosses the phase threshold 0.5. All panels share the 0–1 color scale.

## Figure 4 — Device-level quantities

Reference and predicted active phase fraction in the ROI, maximum temperature,
top terminal current, and integrated Joule power. The dashed line is the frozen
event-fraction threshold. No neural arm produces an event. The MF-containing
arms form a large slowly varying temperature response while nearly suppressing
current and Joule power; raw and sampler-only retain more electrical response but
still miss phase activation.

## Figure 5 — Metrics and claim boundary

Local nominal scalar errors and the resulting evidence boundary. The identical
small primary score is not shown as success because it is generated by an empty
predicted active set against a sparse reference event. No arm is eligible, no
candidate exists, and sealed-case claims remain unavailable.
