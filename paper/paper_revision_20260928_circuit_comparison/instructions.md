## 3. 唯一新预测器：固定not-a-knot三次样条

角色命名`CS`，旧方法保持`PCHIP`。

使用已有项目兼容环境，优先SciPy 1.14.1、FP64；记录实际版本。无需为此建立全新依赖体系。

```python
cs = CubicSpline(
    (obs_time - t0) / 1e-6,
    obs_voltage,
    axis=0,
    bc_type="not-a-knot",
    extrapolate=False,
)
tau = (query_time - t0) / 1e-6
v_hat = cs(tau)
dv_hat_dt = cs.derivative(1)(tau) / 1e-6
I_load = (V_in - v_hat) / R_L
I_cap = C * dv_hat_dt
I_device = I_load - I_cap
```

这是待实现接口示意，不是虚构已有函数或已运行命令。实现后提供项目实际可运行的测试、预测、评分及构建命令。

不得改用natural/clamped/periodic、Akima、滤波、平滑参数选择或新的边界导数。禁止外推、裁剪负电流、限制电压后再评分、逐峰平移和时间扭曲。

新方法逐系统预测一次、保存一次，十套预测全部锁定后再读评分量。保存相同字段及多项式系数/断点/时间尺度，足以独立导出电压、导数、三支电流和积分。旧PCHIP直接复用保存预测，不重开其拟合。

## 5. 本次新增分析：同一预测的焦耳能量与时间分配

此部分只消耗两种方法的锁定预测和原V/I，不预测温度、不重新推进热或迟滞。它是追加诊断，不替换原电流目标。

### 5.1 预测能量

当前Vin恒定，定义

\[
\widehat W_D[a,b]
=\frac1{R_L}\int_a^b[V_{in}p(t)-p(t)^2]dt
-\frac C2[p(b)^2-p(a)^2].
\]

以同一分段多项式解析积分。PCHIP/CS的p为三次，多项式平方为六次；用真实断点分段计算，跨段正确累计。内部时间用μs时，积分必须乘`time_scale`，端点能量直接使用SI电容与伏特。不能只调用`pp.integrate`后将结果平方冒充`integral(p**2)`。

聚焦测试可用每段四点Gauss独立核对`integral(p*I_device)`与公式，常值Vin下最高六次可被该规则精确积分至浮点误差；该测试不使用真实参考拟合。

### 5.2 保存轨迹的比较量

保存热功率样本定义为 `P_ref,n=v_n*I_D,n`，使用同层数组。主能量参考为其分段线性插值的精确积分，即原生节点上的梯形积分。

对不在原生轴的区间边界：在**P_ref的分段线性函数**上解析分割积分。

预测在自己的连续多项式上积分，参考是指定的离散功率口径；两者差异同时含预测与原保存离散因素，不能直接当连续热力学误差。

### 5.3 固定区间与输出

两方法均输出：

- 原主/辅助三个窗口的W_D、带符号及绝对差（J、nJ）；
- 197个共同观测边界形成的全部196个区间能量及误差，最后区间32 ns不改；
- 在这些边界上的累计能量误差；
- `sum_j(abs(ΔW_j))`、`abs(sum_j ΔW_j)`及最大区间绝对误差，展示相消。

已有电荷结果继续保留。电荷Q、电阻耗散W、电容储能E_C、源能量、负载耗散不混用。参考能量近零时不强行报告相对百分比。

“全程W接近而分时段差”与“分时段W也接近”均如实报告；后者仍不能认证内部热场、历史或材料本构。

### 5.4 与Euler原生记账分开

令Δv_n=v_{n+1}−v_n、h_n为原步长，保存定义的κ如上，则

\[
\sum h_n v_n I_{D,n}
=\sum h_n\frac{v_n(V_{in,n}-v_n)}{R_L}
-\frac C2(v_N^2-v_0^2)
+\frac C2\sum(\Delta v_n)^2
-\sum h_n v_n\kappa_n.
\]

只在完整原生步构成的主/两个辅助窗口核查该式，报告Euler左和、梯形能量及其差。`+0.5*C*sum(Δv**2)`是离散项，不是另加的真实热源。

按FP64运算/求和尺度检查代数闭合，不用科学误差门代替；不要求梯形参考同时满足左和恒等式。
